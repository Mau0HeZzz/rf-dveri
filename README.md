# РФ Двери: вёрстка

Статичная вёрстка на Vite (MPA): HTML собирается из партиалов (posthtml), стили на SCSS, скрипты на чистом JS.

## Требования

- Node.js 20.19+ или 22.12+ (требование Vite 8). Проверено на Node 24.
- npm.

## Запуск

```bash
npm install
npm run dev
```

Dev-сервер: http://localhost:3000.
- `/` — разводящая страница со списком страниц.
- `/pages/home.html` — главная.

В режиме разработки запросы к `/udata/...` проксируются на `https://www.rf-dveri.ru` (см. `server.proxy` в `vite.config.js`). Поэтому подсказки поиска работают на настоящих данных.

## Сборка

```bash
npm run build
```

Результат попадает в `dist/`:

```
dist/
  index.html            разводящая страница
  pages/*.html          страницы
  assets/app.js         все скрипты одним файлом
  assets/style.css      все стили одним файлом
  img/, fonts/, video/  статика из public/ как есть
```

Пути к картинкам в CSS относительные (`../img/...`): `assets/style.css` ждёт папку `img` уровнем выше, рядом с `assets`. Пути в HTML абсолютные (`/img/...`).

Посмотреть собранную версию локально:

```bash
npm run preview
```

## Где что лежит

| Путь | Что там |
|---|---|
| `pages/*.html` | Страницы. Каждый `.html` в папке автоматически становится точкой входа сборки |
| `src/html/_*.html` | Партиалы: шапка, подвал, карточки, попапы. Подключаются через `<include src="..." locals='{...}'>` |
| `src/scss/` | Стили. `style.scss` — точка входа, блоки страниц разнесены по файлам (`header.scss`, `home.scss`, `footer.scss` и т. д.) |
| `src/scss/base/colors-palette.scss` | Все цвета проекта в CSS-переменных |
| `src/js/app.js` | Точка входа скриптов, подключение модулей |
| `src/js/files/` | Модули: шапка и меню (`header.js`), подсказки поиска (`search-hints.js`), слайдеры (`sliders.js`), карта магазинов (`shops-map.js`) и т. д. |
| `public/` | Статика: картинки, шрифты, видео. Копируется в `dist` без обработки |

## Заметки для интеграции

### Подсказки поиска

Форма поиска в шапке (`src/html/_header.html`):

```html
<form action="/search/search_do/" data-search-hints
      data-hints-link="/udata/search/getSearchHints/{query}/.json"
      data-hints-min-length="3">
  <input type="search" name="search_string" ...>
```

- `data-hints-link` — адрес API, `{query}` заменяется на введённый текст.
- `data-hints-min-length` — со скольки символов отправлять запрос.
- Из ответа берутся `hintsCategory.result` (подпись «Категория») и `hintsOften.result` (подпись «Популярный запрос»), у каждой подсказки нужны `name` и `link`.
- «Показать все результаты» ведёт на `action` формы с введённым запросом.

### Карточки товаров

- `src/html/_product-card-new.html` — карточка со скидкой и флажками (верхние ряды «Хитов» и «Распродажи»).
- `src/html/_product-card-wide.html` — широкая карточка без скидки (входные двери).
- Флажки — `.product-card__flag`, их может быть несколько. Цвет флажка задаётся инлайн: `style="--flag-color: #FB6D3F"`. По умолчанию флажок зелёный. Уголок под флажком темнее его цвета автоматически, свой цвет уголка — `--flag-fold`.

### Ряды карточек, акции, отзывы

На десктопе количество карточек в ряду одинаковое вплоть до 768 px:

| Блок | Десктоп (≥ 768) | Телефоны |
|---|---|---|
| Хиты продаж, Распродажа | 6 в ряд | слайдер по 3 (520–767) и по 2 |
| Скидки и акции | 4 в ряд | слайдер по 2 (520–767) и по 1 |
| Отзывы | слайдер по 4 | слайдер по 2 (520–767) и по 1 |

### Баннеры главной

Баннер — фото на всю площадь и необязательная подпись:

```html
<a href="#" class="hero__banner">
  <img class="hero__cover" src="..." alt="">
  <div class="hero__caption">
    <p class="hero__caption-title">Заголовок</p>
    <p class="hero__caption-text">Текст</p>
  </div>
</a>
```

Без `.hero__caption` баннер — просто картинка. Если текст нарисован на самой картинке, опишите его в `alt`.

### Меню

- **Большое меню каталога** (десктоп) — вложенные списки `.catalog-menu__list` внутри `.catalog-menu__section`. Каждый уровень вложенности открывается следующей колонкой. Модификатор `.catalog-menu__list--groups` показывает пункты верхнего уровня отдельными колонками с заголовками, без каскада (так сделаны «Производители»).
- **Баннеры в меню каталога** — у каждого раздела свой вертикальный слайдер `.catalog-menu__promo`, баннер подключается партиалом `_catalog-banner.html`.
- **Мобильное меню** не дублирует данные: пункт с `data-submenu="<CSS-селектор списка>"` строит подменю из разметки десктопных меню.

### Вопросы и ответы

Аккордеон на шаблонном модуле спойлеров (`data-spollers` на списке, `<details>`/`<summary>` на пунктах). Атрибут `data-open` у `<details>` — пункт раскрыт при загрузке.

### Попапы

Попап «Связаться с нами» — `src/html/_contact-popup.html`, `id="contact"`. Открывается любым элементом с `data-popup="#contact"`.
